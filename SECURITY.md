# Security Policy

## Supported Versions

As this project is a purely client-side static web application with an optional lightweight Python runner, security updates are applied to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability, please do not disclose it publicly in an open GitHub issue.

Instead, please report it privately:
1. Open a [Draft Security Advisory](https://github.com/tripping-alien/bijective_base6_calc/security/advisories/new) via GitHub Security tab, or
2. Contact the maintainers directly through GitHub.

We will review the report, investigate the impact, and provide a patch in a timely manner.
